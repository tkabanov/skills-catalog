# Contributing

Changes go in through pull requests only: `main` is protected, direct pushes are blocked for everyone.

1. Fork the repo and create a branch.
2. Add or change a skill in `skills/<name>/` (a `SKILL.md` with `name` and `description` frontmatter, plus any scripts or assets it needs; no `node_modules`).
3. If you add a skill, list it in the table in `README.md`.
4. Open a pull request describing what the skill does and how you tested it.
